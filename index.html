Web design · Web development

Rack. Monitor. Maintain. Improve.

A machine tracking and maintenance system for apparel factories. It covers machine records, machine health, maintenance planning, repairs, spare parts and analytics.

It began as a group project and is now my own work. It’s a working model that runs on data from my apparel internship and my own research. I built it with web design and web development.

FitMatrix.AI

Python · Deep learning

A more personal way to find the right fit.

A fashion-tech concept for sizing and fit in online shopping. It will use a phone’s camera and LiDAR sensor to make a fit heat map, recommend brands and sizes, and act as an AI stylist.

I built the deep learning model alone, using Python. Training it is the next step.
